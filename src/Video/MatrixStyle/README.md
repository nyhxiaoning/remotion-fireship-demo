# MatrixStyle 组合使用说明

- 放置合法授权的素材到 `public/videos/matrix/`（推荐使用官方发布的片段、获得授权的素材或 CC/免版权素材）。
- 本项目不提供或指导下载受版权保护的影片片段，请确保你拥有使用权。
- 在 `src/Video/MatrixStyle/index.tsx` 中替换 `clips` 列表为你的素材路径。

## 替代提示词（合法合规）

用于指导创作“矩阵风格”的高燃短视频，而不涉及违法下载：

1. 「以矩阵美学为主题，用合法授权或免版权素材，绿码雨叠加、强对比与轻微故障效果，快速剪切节奏，配合鼓点音轨，打造 15–20 秒的高燃科技感短视频。」
2. 「使用你自有版权的赛博朋克/科技题材素材，应用绿色色调、暗角与代码雨 Overlay，交替推进/拉远镜头，每 2 秒切换一镜，结尾以 Logo/标题收尾。」

## 技术要点（Remotion Best Practices）

- 使用 `Series` 组织片段；用 `Sequence` 叠加音轨与特效层。
- 所有外部资源通过 `staticFile()` 引用，放在 `public/` 下。
- 尽量使用 `AbsoluteFill`、`objectFit: 'cover'` 保证不同素材尺寸的统一画面。
- 过渡与动效使用 `spring`/`interpolate` 控制，避免硬切造成突兀。
